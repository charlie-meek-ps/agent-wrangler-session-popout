# Changelog

## 1.0.0 — 2026-10-14

First public release.

- Pop out a live agent terminal into its own movable, resizable window.
- Use **Control + Command + O (⌃⌘O)** or the session's action menu.
- Return the same session to the board through a compact icon.
- Reconnect automatically after interruptions, with Retry available if recovery fails.
- Inherit Wrangler's theme, wallpaper, UI font and terminal font size, including live changes.
- Keep the original agent process running while moving between views.
